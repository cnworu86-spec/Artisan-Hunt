# Artisan Hunt

Artisan Hunt is a mobile platform designed to connect customers with skilled artisans, making it easier for users to discover and connect with service providers across Ghana.

The project was developed collaboratively as a final-year project and consists of three main components:

- React Native mobile application
- Node.js/Express backend
- React-based admin dashboard

## My Contribution

As a member of the development team, my main contributions included:

- **Frontend Development:** Worked on the user-facing interface and application experience.
- **KYC Verification:** Contributed to the implementation of the Know Your Customer (KYC) verification functionality.
- **Authentication & Security:** Implemented password hashing using **bcrypt** to securely handle user passwords.
- **Backend Development:** Contributed to backend development with the assistance of AI development tools. I reviewed, tested, modified and integrated the generated code into the application.
